
# Downly

Aplicativo PWA para organizar e facilitar o acesso a conteúdos de vídeo autorizados.

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS (planejado)
- Lucide React
- Progressive Web App (PWA)

## Executar localmente

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

Os arquivos de produção serão gerados na pasta `dist`.

## Funcionalidades iniciais

- Interface responsiva para dispositivos móveis.
- Reconhecimento de links do Instagram e Facebook.
- Histórico de links verificados durante a sessão.
- Navegação entre Início, Histórico e Ajustes.
- Preparação para instalação como PWA.

## Download de conteúdo

A versão inicial ainda não realiza downloads. Futuras integrações deverão utilizar recursos oficiais e respeitar as permissões, os direitos autorais e as regras das plataformas.

## Publicação

Projeto preparado para publicação no Cloudflare Pages.
